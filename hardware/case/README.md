# 3D-printed controller housing

The same enclosure is supplied in three formats:

| File | Use |
| --- | --- |
| [`kiln-controller-housing.3mf`](kiln-controller-housing.3mf) | Preferred source for a slicer that supports 3MF |
| [`kiln-controller-housing.stl`](kiln-controller-housing.stl) | Widely compatible triangle mesh |
| [`kiln-controller-housing.step`](kiln-controller-housing.step) | Editable CAD solid for changing openings and mounts |

Verify the imported scale, wall thickness, screw holes, connector openings and clearances before printing. Different suppliers may sell modules with different board dimensions even when the product name is the same. Choose print material and placement for the temperature expected at the controller's installed location.

The photos in [`../photos`](../photos/README.md) show the completed housing and component layout used for the documented build.
