# Changelog

This history was reconstructed from the supplied working v0.4 project and the accessible development conversation. The source snapshots and full discussion for the earliest releases are not available, so uncertain details remain clearly marked.

## 0.4.1

The supplied working v0.4 project identifies itself as `0.4.1`. The accessible discussion does not describe the exact change from 0.4.0 to 0.4.1. In this source, real heater output is enabled and configured for a PWM-to-0–10 V interface.

## 0.4.0

### Added

- Embedded, smoother Inter Display-based fonts.
- Nominal program duration in the local program browser, program start screen and web program cards.

### Changed

- Encoder menus use partial row updates to reduce full-screen flashing.
- Manual temperature, manual power, delayed-start and recovery screens update only the changing areas.
- Increased the size of current-temperature and secondary dashboard text.
- Replaced abbreviated timing labels with **Elapsed** and **Remaining**.

## 0.3
