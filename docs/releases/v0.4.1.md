# Kiln Controller v0.4.1

Release-note draft for the supplied working v0.4-series firmware.

This release contains the current ESP32-S3 kiln controller with local display and encoder controls, PID ramp/hold programs, a responsive web interface and browser-based OTA updates.

The v0.4 interface improves readability and responsiveness with partial screen redraws, embedded smoother fonts, larger temperature and dashboard text, full **Elapsed** and **Remaining** labels, and planned program duration in the local and web program browsers.

The hardware used for this build converts the 2 kHz, 12-bit PWM signal on GPIO39 to a 0–10 V command for the kiln power regulator. The output stage can be replaced or adapted for other electric-kiln control interfaces. Builders must use correctly rated and suitably isolated hardware for their kiln.

The supplied working source has `ENABLE_REAL_HEATER_OUTPUT = true`. Set it to `false` for dry testing without a physical heater command, and verify the complete control chain before enabling real output.

For OTA from v0.3, build the `esp32-s3` environment and upload `.pio/build/esp32-s3/firmware.bin` through **Settings → System / firmware** while the kiln is idle. After reboot, verify firmware **0.4.1** and confirm that saved programs and settings remain available.

Verification: a clean PlatformIO release build completed successfully on 2026-09-26. It used 92,456 bytes of RAM and 971,497 bytes of application flash. Hardware and OTA behavior were not retested as part of repository preparation.
